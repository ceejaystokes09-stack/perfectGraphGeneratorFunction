Chart API reference

Use the column names from your CSV or JSON exactly as written, including capitalization. The examples below use Genre, Subscription Type, and numeric Listeners columns.

Input data

chart(data, options?)
Start a chart builder. data may be row objects, column arrays, a numeric array, CSV text, JSON text, or a Chart.js config. options can set format to "csv", "json", or "tsv".
chartjs.parseCSV(text, options?)
Parse CSV to row objects. Options: delimiter (default comma), header (default true), and dynamicTyping (default true).
chartjs.parseJSON(text) / chartjs.parseData(input, options?)
Parse JSON directly, or automatically parse CSV/JSON input. Use parseData when you need an explicit format.
await chartjs.fromFile(file, options?)
Read a browser File or Blob and return a builder. The filename extension is used to infer CSV or JSON.
await chartjs.fromURL(url, options?)
Fetch a same-origin or CORS-enabled data URL and return a builder. Options may include format and fetchOptions.

Chart types and mappings

.plot(type, mapping?) selects any Chart.js type; .type(type) is an alias. Convenience methods are .line(mapping), .scatter(mapping), .bar(mapping), .area(mapping), .pie(mapping), .doughnut(mapping), .histogram(mapping), .box(mapping), .violin(mapping), and .heatmap(mapping).

.x(field), .y(field)
Set the x or y field mapping separately instead of passing it to a chart-type method.
.labels(field), .values(field)
Set the category labels and values fields used by pie and doughnut charts.
{ x, y }
Map columns to axes. For line, bar, and area charts, y can be one column or an array of columns. Bar charts combine repeated x labels.
{ labels, values }
Map category labels and numeric values for pie and doughnut charts.
{ x, y, r }
Map numeric horizontal, vertical, and radius columns for a bubble chart, using .plot("bubble", mapping).
{ x, y, z }
Heatmaps use x/y labels and a 2D numeric z matrix. Histograms use x or y for the numeric input column. Box and violin charts use y for one or more numeric columns.
chart(rows).line({ x: "Month", y: ["Sales", "Costs"] });
chart(rows).pie({ labels: "Genre", values: "Listeners" });
chart(rows).plot("bubble", { x: "Age", y: "Listeners", r: "Count" });

Grouping and reductions

.groupBy(field)
Choose the x/category field to group on. Repeated values become one chart label.
.sum(field?), .mean(field?), .median(field?)
Reduce numeric values per x group. If field is omitted, the current y mapping is used.
.min(field?), .max(field?), .range(field?)
Return the smallest value, largest value, or max-minus-min for each group.
.count(field?)
Count non-empty values. For a categorical y field, produce one series per category and count rows within each x group.
.std(field?), .var(field?)
Calculate sample standard deviation or sample variance per group.
.aggregate(method, field?) / .agg(method, field?)
Generic form. Supported methods: sum, mean, median, min, max, range, count, std, and var.
// Count subscription types within each genre.
chart(rows).bar({ x: "Genre", y: "Subscription Type" }).count();

// Sum a numeric column for each genre.
chart(rows).groupBy("Genre").sum("Listeners").bar();

// Average a numeric column for each genre.
chart(rows).groupBy("Genre").mean("Listeners").bar();

Labels, styling, and output

.title(text), .xlabel(text), .ylabel(text)
Set the chart title and axis titles.
.colors(colorOrArray) / .color(color)
Set one color or a palette for datasets/categories. .color() is an alias for .colors().
.bins(count)
Set the number of bins for a histogram.
.trace(options), .layout(options), .config(options)
Pass Chart.js dataset options, chart options, or top-level config options.
.toConfig() / chartjs.buildConfig(data, settings?)
Build a Chart.js configuration without rendering it. settings may contain kind/type, field mappings, aggregation, title, xlabel, ylabel, colors, trace, options, and config.
.render(target, options?)
Render to a canvas or an element containing a canvas. Returns the Chart.js instance. options may specify a Chart constructor or config overrides.
.downloadImage(filename?, options?) / .download(filename?, options?)
Download the rendered chart. Options accept an image type (PNG by default) and quality.
chartjs.downloadImage(chartOrCanvas, filename?, options?)
Standalone version of image export for an existing Chart.js instance or canvas.
const builder = chart(rows)
  .bar({ x: "Genre", y: "Listeners" })
  .sum()
  .colors(["#14745c", "#e06b43"])
  .title("Total listeners by genre")
  .xlabel("Genre")
  .ylabel("Listeners");

builder.render("#chart");
builder.downloadImage("listeners.png");
